# Data

* `strains.tsv` — the 30 genomes analysed (29 strains and the reference YJ016): published designation, identifier used in file names (`file_id`), origin, lineage, assembly accession, BioProject and statistics of the filtered assembly. This is Table S1 of the article in machine-readable form.

Not stored here:

* **MIC values** for the 116-isolate collection: Zenodo, [doi:10.5281/zenodo.20679806](https://doi.org/10.5281/zenodo.20679806). Save the workbook as `data/mic/MICs_all_Vv.xlsx`.
* **Filtered assemblies** of the 29 strains, as analysed: Zenodo, [doi:10.5281/zenodo.23639878](https://doi.org/10.5281/zenodo.23639878). Save them as `data/genomes/<file_id>.fna`.
* **Reference genome** YJ016 (GCF_000009745.1) and the deposited assemblies: NCBI.
* **Bakta light database v6.0**: [doi:10.5281/zenodo.14916843](https://doi.org/10.5281/zenodo.14916843).
* **NCBI 16S ribosomal RNA database** (Bacteria and Archaea type strains), downloaded with `update_blastdb.pl 16S_ribosomal_RNA` on 21 July 2026.
